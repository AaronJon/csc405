Questions 1 to 10

  1. 1

    Write a script hello.pl that prints your group name and the names of all members, one per line. Run it with perl hello.pl, then make it executable and run it as ./hello.pl.

  2. 2

    Write a script that asks the user for their name and programme of study, then prints a welcome message that uses both.

  3. 3

    Write a script that asks for two numbers and prints their sum, difference, product, quotient and remainder.

  4. 4

    Write a temperature converter that reads a value in Celsius and prints the Fahrenheit and Kelvin equivalents, both rounded to one decimal place.

  5. 5

    Write a script that reads a radius and prints the area and circumference of a circle. Store the value of pi in a variable.

  6. 6

    A school canteen sells rice at GHS 12, a drink at GHS 3 and a snack at GHS 5. Ask for the quantity of each item and print an itemised bill with a total. Use printf so the amounts line up with two decimal places.

  7. 7

    Add use strict and use warnings to your canteen script. Then deliberately introduce three different mistakes (for example a misspelled variable, a missing semicolon, and an undefined variable) and record the error or warning each one produces.

  8. 8

    Write a script that reads a number from the user and prints its multiplication table from 1 to 12, neatly formatted.

  9. 9

    Use perldoc to look up the functions length, uc, lc, ucfirst and substr. Write a script that demonstrates each one on a sentence of your choice, with a comment explaining what each does.

  10. 10

    Create an array of ten student names. Print the first name, the last name and the number of items. Then add two names at the end, remove the first name, and print the final array.

Questions 11 to 20

  1. 11

    Store five exam scores in an array and print the total, average, highest and lowest, without using any modules.

  2. 12

    Repeat the previous question using List::Util (sum, max, min). Compare the two versions: which is shorter, and which is easier to read?

  3. 13

    Store the names of eight students in an array. Print them in alphabetical order, then in reverse alphabetical order, then sorted by the length of the name.

  4. 14

    Create a hash that maps six course codes to course titles. Print all of them sorted by code. Then ask the user for a course code and print the title, or the message "Course not found".

  5. 15

    Store the balances of three wallets (for example MTN, Telecel and AirtelTigo) in a hash. Write code to deposit into a wallet, withdraw from a wallet (refusing the withdrawal if the balance is too low), and print the final balances.

  6. 16

    Write a script that takes a list of words and counts how many times each word appears, using a hash. Print the result from most frequent to least frequent.

  7. 17

    Given an array that contains duplicates, such as (3, 7, 3, 9, 7, 1), build a new array with the duplicates removed while keeping the original order.

  8. 18

    Create an array of arrays holding the scores of five students in three subjects. Print a table showing each student's total and average.

  9. 19

    Use an array of hashes to store records for five students (name, index number, programme, level). Print all records as a formatted table, then print only the Level 300 students.

  10. 20

    Read a score between 0 and 100 and print a grade using a grading scale your group chooses (A to F). Reject values outside the range.

Questions 21 to 30

  1. 21

    Write a number guessing game. The program picks a random number from 1 to 50, the user has 7 tries, and the program says "higher" or "lower" after each wrong guess.

  2. 22

    Print all even numbers from 1 to 100. Then print all numbers from 1 to 100 that are divisible by both 3 and 5.

  3. 23

    FizzBuzz: for the numbers 1 to 50, print "Fizz" for multiples of 3, "Buzz" for multiples of 5, and "FizzBuzz" for multiples of both; otherwise print the number. Then change the program so the words and divisors come from a hash.

  4. 24

    Write a script that checks whether a number entered by the user is prime. Extend it to list all prime numbers up to a limit entered by the user.

  5. 25

    The user has a 4-digit PIN and 3 attempts to enter it. After a correct PIN, show a menu (balance, deposit, withdraw, exit) that repeats until the user chooses exit.

  6. 26

    Print a right-angled triangle of stars whose height is given by the user, then print an inverted version.

  7. 27

    Write a script that computes the factorial of a number using a loop, and a second one that prints the first N terms of the Fibonacci sequence.

  8. 28

    Fares depend on the distance band (up to 5 km, 5 to 15 km, over 15 km) and the passenger type (adult, student, child). Ask for both and print the fare. Store the rates in a hash instead of writing a long if-elsif chain.

  9. 29

    Using last and next, write a loop that reads numbers from the user until they type "done". Ignore negative numbers, and print the sum and count of the valid ones.

  10. 30

    Read a sentence and print the number of characters, words and vowels in it.

Questions 31 to 40

  1. 31

    Check whether a word or phrase is a palindrome, ignoring case, spaces and punctuation.

  2. 32

    Take a full name typed in any case, such as "kwame ANOKYE mensah", and print it properly capitalised ("Kwame Anokye Mensah").

  3. 33

    Validate Ghanaian mobile numbers: accept forms such as 0244123456 and +233244123456, and reject everything else. Test your pattern on at least 10 inputs and show the results.

  4. 34

    A text file contains messy lines with email addresses buried inside them. Use a regular expression to extract every email address and print the unique ones in alphabetical order.

  5. 35

    Write a script that validates student index numbers in a format your group defines (for example PS/CSC/23/0045). Show it accepting at least 5 valid numbers and rejecting at least 5 invalid ones.

  6. 36

    Use the substitution operator s/// to replace every occurrence of a word in a paragraph, ignoring case, and report how many replacements were made.

  7. 37

    A file contains dates written as 28/10/2026. Convert every date to the format 2026-10-28 using regular expression captures, and leave the rest of each line unchanged.

  8. 38

    Use split to break the CSV line "Ama,Adzovi,CSC,300,72" into fields and print each one with a label. Then use join to print the fields separated by " | ".

  9. 39

    Read a paragraph and find the longest word, the shortest word, and the ten most common words, ignoring common words such as "the", "and" and "is".

  10. 40

    Write a script that reads a text file and prints every line with its line number. Create your own test file.

Questions 41 to 50

  1. 41

    Write a script that counts the lines, words and characters in a file, like the wc command. Compare your output with the output of wc.

  2. 42

    Create a file scores.txt with lines in the form Name,Score. Read it and print the average, the highest and the lowest score, together with the names of the students who got them.

  3. 43

    A file has lines such as 2026-10-12,Ama,Present. Produce a report showing, for each student, the number of days present and absent and the attendance percentage. Flag anyone below 75 percent.

  4. 44

    Write a script that appends a timestamped message to a log file every time it runs. Run it several times and show the contents of the file.

  5. 45

    Write a one-liner that prints only the lines of a log file containing the word "error" in any case. Show it working on a sample log.

  6. 46

    Write a one-liner that prints the first column of a space-separated file.

  7. 47

    Write a one-liner that replaces every "colour" with "color" in a file, editing the file in place while keeping a backup. Show that the backup file was created.

  8. 48

    Write a one-liner that counts the lines in a file that are not blank.

  9. 49

    Read a file with each student's name, index number and three course scores. Compute the total, average, grade and rank for each student, print a report sorted by rank, and also write it to a file.

  10. 50

    A file lists group names. Randomly assign each group a 15-minute presentation slot starting at 9:00 am, with no slots between 12:00 and 1:00 pm, and print the full schedule.
