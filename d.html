Questions 1 to 10

  1. 1

    Write a script intro.pl that prints your group name, a date of your choice, and the names of all members, one per line. Run it with perl intro.pl, then make it executable and run it as ./intro.pl.

  2. 2

    Write a script that asks the user for their name and their favourite subject, then prints a message that uses both.

  3. 3

    Write a script that asks for two numbers and prints the larger one, their sum, product, quotient and remainder.

  4. 4

    Write a script that reads a distance in kilometres and prints the equivalent in miles and in metres, both rounded to two decimal places.

  5. 5

    Write a script that reads the length and width of a rectangular classroom floor in metres and prints the area and the perimeter, then prints the cost of tiling the floor at GHS 45 per square metre. Store the tile price in a variable.

  6. 6

    A provision store sells a loaf of bread at GHS 10, a tin of milk at GHS 7 and a bag of sugar at GHS 15. Ask for the quantity of each item and print an itemised bill with a total. Use printf so the amounts line up with two decimal places.

  7. 7

    Add use strict and use warnings to your provision store script. Then deliberately introduce three different mistakes (for example a missing comma in a list, an unclosed bracket, and a misspelled variable) and record the error or warning each one produces.

  8. 8

    Write a script that reads a number from the user and prints its multiplication table from 12 down to 1, neatly formatted.

  9. 9

    Use perldoc to look up the functions sort, grep, map, keys and values. Write a script that demonstrates each one on an array or hash of your choice, with a comment explaining what each does.

  10. 10

    Create an array of ten medicine names for a pharmacy. Print the first medicine, the last medicine and the number of items. Then add one medicine at the beginning, remove the last two, and print the final array.

Questions 11 to 20

  1. 11

    Store eight monthly electricity bills (in GHS) in an array and print the total, average, highest and lowest, without using any modules.

  2. 12

    Repeat the previous question using List::Util (sum, max, min). Compare the two versions: which is shorter, and which is easier to read?

  3. 13

    Store the names of nine courses from your programme in an array. Print them in alphabetical order, then in reverse alphabetical order, then sorted by the length of the name.

  4. 14

    Create a hash that maps seven staff IDs to staff names. Print all of them sorted by ID. Then ask the user for a staff ID and print the name, or the message "Staff not found".

  5. 15

    Store the balances of three savings accounts (for example Savings, School Fees and Emergency) in a hash. Write code to deposit into an account, withdraw from an account (refusing the withdrawal if the balance is too low), and print the final balances.

  6. 16

    Write a script that takes a line of text typed by the user and counts how many times each letter appears, using a hash. Print the result from most frequent to least frequent.

  7. 17

    Given an array that contains duplicates, such as (10, 20, 10, 30, 20, 40, 30, 50), build a new array with the duplicates removed while keeping the original order.

  8. 18

    Create an array of arrays holding the weekly rainfall (in mm) of four towns over three weeks. Print a table showing each town's total and average.

  9. 19

    Use an array of hashes to store records for five products (name, code, category, price). Print all records as a formatted table, then print only the products in the Drinks category.

  10. 20

    Read the number of electricity units used, between 0 and 1000, and print the tariff band (Low, Medium or High) using boundaries your group chooses. Reject values outside the range.

Questions 21 to 30

  1. 21

    Write a number guessing game. The program picks a random number from 1 to 200, the user has 10 tries, and the program says "go higher" or "go lower" after each wrong guess.

  2. 22

    Print all numbers from 1 to 100 that are divisible by 7. Then print all numbers from 1 to 300 that are divisible by both 6 and 9.

  3. 23

    FizzBuzz variant: for the numbers 1 to 90, print "Red" for multiples of 5, "Blue" for multiples of 8, and "Purple" for multiples of both; otherwise print the number. Then change the program so the words and divisors come from a hash.

  4. 24

    Write a script that checks whether a number entered by the user is an Armstrong number (a number equal to the sum of its digits, each raised to the power of the number of digits, for example 153). Extend it to list all Armstrong numbers up to a limit entered by the user.

  5. 25

    A campus canteen smart-card machine asks for a 4-digit PIN and allows 3 attempts. After a correct PIN, show a menu (check balance, top up, pay for a meal, exit) that repeats until the user chooses exit.

  6. 26

    Print a right-angled triangle of letters (A, then A B, then A B C, and so on) whose height is given by the user, then print an inverted version.

  7. 27

    Write a script that computes the sum of the first N odd numbers using a loop, and a second one that prints the first N terms of the Fibonacci-style sequence that starts with 2 and 3.

  8. 28

    An electricity company charges by usage band (up to 50 units, over 50 up to 200 units, over 200 units) and customer type (residential, commercial, industrial). Ask for the number of units and the customer type, then print the rate per unit and the total bill. Store the rates in a hash instead of writing a long if-elsif chain.

  9. 29

    Using last and next, write a loop that reads numbers from the user until they type "finish". Ignore numbers outside the range 0 to 100, and print the sum and count of the valid ones.

  10. 30

    Read a sentence and print the number of characters, words and consonants in it.

Questions 31 to 40

  1. 31

    Check whether a sentence is a pangram (it uses every letter of the English alphabet at least once, for example "The quick brown fox jumps over the lazy dog"). Test it on at least six sentences and show the results.

  2. 32

    Take a full name typed in any case, such as "kojo AGYEMANG asare", and print it properly capitalised ("Kojo Agyemang Asare").

  3. 33

    Validate Ghanaian vehicle registration numbers: accept two capital letters, a space, one to four digits, a hyphen and two digits (for example GR 1234-22 or GT 567-19), and reject everything else. Test your pattern on at least 10 inputs and show the results.

  4. 34

    A text file contains messy lines with amounts written like GHS 45.50 or GHS 1200 buried inside them. Use a regular expression to extract every amount and print the total of all of them.

  5. 35

    Write a script that validates invoice numbers in a format your group defines (for example INV-2026-0042). Show it accepting at least 5 valid numbers and rejecting at least 5 invalid ones.

  6. 36

    Use the substitution operator s/// to replace every digit in a paragraph with the letter X, and report how many digits were replaced.

  7. 37

    A file contains names written as "Mensah, Kwame". Convert every name to the form "Kwame Mensah" using regular expression captures, and leave the rest of each line unchanged.

  8. 38

    Use split to break the line "Adjoa|Frimpong|BIO|100|81", whose fields are separated by vertical bars, into fields and print each one with a label. Then use join to print the fields separated by " - ".

  9. 39

    Read a paragraph and find the words that appear only once, the longest word, and the five most common words, ignoring common words such as "a", "in" and "of".

  10. 40

    Write a script that reads a text file and prints every line with its line number padded with leading zeros (001, 002, ...). Create your own test file.

Questions 41 to 50

  1. 41

    Write a script that counts the lines, words and characters in a file, and also prints the number of lines that contain a word entered by the user. Compare your first three counts with the output of wc.

  2. 42

    Create a file sales.txt with lines in the form Branch,Amount. Read it and print the total sales, the best branch and the weakest branch, together with their amounts.

  3. 43

    A lecture log has lines such as 2026-10-12,CSC405,Held or 2026-10-12,CSC405,Cancelled. Produce a report showing, for each course, the number of lectures held and cancelled and the percentage held. Flag any course below 80 percent.

  4. 44

    Write a script that keeps a run counter in a file: each time it runs, it reads the count, adds one, saves it, and prints "This script has run N times". Run it several times and show the contents of the file.

  5. 45

    Write a one-liner that prints only the lines of a log file that begin with the year 2026. Show it working on a sample log.

  6. 46

    Write a one-liner that prints the first and third columns of a space-separated file.

  7. 47

    Write a one-liner that replaces every "organise" with "organize" in a file, editing the file in place while keeping a backup with the extension .old. Show that the backup file was created.

  8. 48

    Write a one-liner that counts the lines in a file that begin with a capital letter.

  9. 49

    Read a file with each shop's name, branch code and sales for four weeks. Compute the total, average, rating (using a scale your group chooses) and rank for each shop, print a report sorted by rank, and also write it to a file.

  10. 50

    A file lists the names of courses. Randomly assign each course a 30-minute exam session starting at 7:30 am, with no sessions between 10:00 and 11:00 am, and print the full schedule.
