Questions 1 to 10

  1. 1

    Write a script welcome.pl that prints your group number, the course code CSC405, and the name and index number of every member, one per line. Run it with perl welcome.pl, then make it executable and run it as ./welcome.pl.

  2. 2

    Write a script that asks the user for their name and their level (100, 200, 300 or 400), then prints a personalised message that uses both.

  3. 3

    Write a script that asks for two numbers and prints their sum, product, average, integer quotient and remainder.

  4. 4

    Write a temperature converter that reads a value in Fahrenheit and prints the Celsius and Kelvin equivalents, both rounded to two decimal places.

  5. 5

    A farmer has a circular plot of land. Write a script that reads its radius in metres and prints the area and the perimeter, then prints the cost of fencing it at GHS 15 per metre. Store the value of pi in a variable.

  6. 6

    A campus bookshop sells a notebook at GHS 8, a pen at GHS 2.50 and a folder at GHS 6. Ask for the quantity of each item and print an itemised bill with a total. Use printf so the amounts line up with two decimal places.

  7. 7

    Add use strict and use warnings to your bookshop script. Then deliberately introduce three different mistakes (for example a variable used without being declared with my, a missing closing brace, and a text value compared with the numeric operator ==) and record the error or warning each one produces.

  8. 8

    Write a script that reads a number from the user and prints its multiplication table from 1 to 15, neatly formatted.

  9. 9

    Use perldoc to look up the functions index, reverse, join, sprintf and lcfirst. Write a script that demonstrates each one on a sentence of your choice, with a comment explaining what each does.

  10. 10

    Create an array of twelve town names in Ghana. Print the first town, the last town and the number of items. Then add three towns at the beginning, remove the last town, and print the final array.

Questions 11 to 20

  1. 11

    Store seven daily sales figures (in GHS) for a provision shop in an array and print the total, average, highest and lowest, without using any modules.

  2. 12

    Repeat the previous question using List::Util (sum, max, min). Compare the two versions: which is shorter, and which is easier to read?

  3. 13

    Store the names of nine Ghanaian dishes in an array. Print them in alphabetical order, then in reverse alphabetical order, then sorted by the length of the name.

  4. 14

    Create a hash that maps seven product codes to product names. Print all of them sorted by code. Then ask the user for a product code and print the name, or the message "Product not found".

  5. 15

    Store the balances of three bank accounts (for example GCB, Fidelity and Ecobank) in a hash. Write code to deposit into an account, withdraw from an account (refusing the withdrawal if the balance is too low), and print the final balances.

  6. 16

    Write a script that takes a sentence typed by the user, splits it into words, and counts how many times each word appears, using a hash. Print the result from most frequent to least frequent.

  7. 17

    Given an array that contains duplicates, such as (5, 2, 5, 8, 2, 9, 8, 4), build a new array with the duplicates removed while keeping the original order.

  8. 18

    Create an array of arrays holding the monthly sales of four shops over three months. Print a table showing each shop's total and average.

  9. 19

    Use an array of hashes to store records for six books (title, author, year, price). Print all records as a formatted table, then print only the books published after 2015.

  10. 20

    Read a mark between 0 and 100 and print the degree classification (First Class, Second Class Upper, Second Class Lower, Pass or Fail) using boundaries your group chooses. Reject values outside the range.

Questions 21 to 30

  1. 21

    Write a number guessing game. The program picks a random number from 1 to 100, the user has 8 tries, and the program says "too high" or "too low" after each wrong guess.

  2. 22

    Print all odd numbers from 1 to 99. Then print all numbers from 1 to 200 that are divisible by both 4 and 6.

  3. 23

    FizzBuzz variant: for the numbers 1 to 60, print "Ping" for multiples of 4, "Pong" for multiples of 6, and "PingPong" for multiples of both; otherwise print the number. Then change the program so the words and divisors come from a hash.

  4. 24

    Write a script that checks whether a number entered by the user is a perfect number (a number equal to the sum of its proper divisors, such as 6 or 28). Extend it to list all perfect numbers up to a limit entered by the user.

  5. 25

    A mobile money agent terminal asks for a 5-digit agent code and allows 3 attempts. After a correct code, show a menu (check float, add float, pay out cash, exit) that repeats until the user chooses exit.

  6. 26

    Print a right-angled triangle of numbers (1, then 1 2, then 1 2 3, and so on) whose height is given by the user, then print an inverted version.

  7. 27

    Write a script that computes x raised to the power n using a loop (without using the ** operator), and a second one that prints the first N triangular numbers (1, 3, 6, 10, ...).

  8. 28

    A courier company charges by parcel weight band (up to 2 kg, over 2 kg up to 10 kg, over 10 kg) and service type (standard, express, overnight). Ask for both and print the delivery charge. Store the rates in a hash instead of writing a long if-elsif chain.

  9. 29

    Using last and next, write a loop that reads numbers from the user until they type "stop". Ignore numbers greater than 100, and print the sum and count of the valid ones.

  10. 30

    Read a sentence and print the number of characters (not counting spaces), words and digits in it.

Questions 31 to 40

  1. 31

    Check whether a number entered by the user is a palindrome (for example 12321). Test it on at least eight numbers and show the results.

  2. 32

    Take a full name typed in any case, such as "ama SERWAA boateng", and print it properly capitalised ("Ama Serwaa Boateng").

  3. 33

    Validate Ghanaian mobile numbers: accept forms such as 0501234567 and +233501234567, and reject everything else. Test your pattern on at least 12 inputs and show the results.

  4. 34

    A text file contains messy lines with web addresses (starting with http:// or https://) buried inside them. Use a regular expression to extract every address and print the unique ones in alphabetical order.

  5. 35

    Write a script that validates course codes in a format your group defines (for example CSC405 or INF107D). Show it accepting at least 6 valid codes and rejecting at least 6 invalid ones.

  6. 36

    Use the substitution operator s/// to replace a word in a paragraph, ignoring case, but only when it appears as a whole word (so that replacing "cat" does not change "category"). Report how many replacements were made.

  7. 37

    A file contains dates written as 2026-10-28. Convert every date to the format 28/10/2026 using regular expression captures, and leave the rest of each line unchanged.

  8. 38

    Use split to break the CSV line "Kofi,Boateng,MTH,200,64" into fields and print each one with a label. Then use join to print the fields separated by " ; ".

  9. 39

    Read a paragraph and find the longest word, the average word length, and the five most common words, ignoring common words such as "of", "to" and "a".

  10. 40

    Write a script that reads a text file and prints every non-blank line with its line number. Create your own test file.

Questions 41 to 50

  1. 41

    Write a script that counts the lines, words and characters in a file, and also reports the length of the longest line. Compare your first three counts with the output of wc.

  2. 42

    Create a file prices.txt with lines in the form Item,Price. Read it and print the average price, the most expensive item and the cheapest item, together with their prices.

  3. 43

  4. 44

  5. 45

  6. 46

    Write a one-liner that prints the last column of a space-separated file.

  7. 47

    Write a one-liner that replaces every "favour" with "favor" in a file, editing the file in place while keeping a backup with the extension .orig. Show that the backup file was created.

  8. 48

    Write a one-liner that counts the lines in a file that contain at least one digit.

  9. 49

    Read a file with each employee's name, staff ID and sales for three months. Compute the total, average, performance rating (using a scale your group chooses) and rank for each employee, print a report sorted by rank, and also write it to a file.

  10. 50

    A file lists the names of candidates. Randomly assign each candidate a 20-minute interview slot starting at 8:30 am, with no slots between 11:00 and 11:30 am, and print the full schedule.
