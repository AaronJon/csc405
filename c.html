Instructions

  7. Submission date: Any day between 11th to 13th November 2026.
  8. About 3 questions from this set will appear in the examination.

Questions 1 to 10

  1. 1

    Write a script team.pl that prints your group name, the number of members, and the names of all members, one per line. Run it with perl team.pl, then make it executable and run it as ./team.pl.

  2. 2

    Write a script that asks the user for their name and their hall of residence, then prints a greeting that uses both.

  3. 3

    Write a script that asks for two numbers and prints their difference, product, quotient (to two decimal places), remainder, and the first number raised to the power of the second.

  4. 4

    Write a temperature converter that reads a value in Kelvin and prints the Celsius and Fahrenheit equivalents, both rounded to one decimal place.

  5. 5

    Write a script that reads the radius of a circular swimming pool in metres and prints its surface area and the length of its edge, then prints the cost of tiling the surface at GHS 40 per square metre. Store the value of pi in a variable.

  6. 6

    A photocopy and printing shop charges GHS 0.50 per photocopied page, GHS 1.00 per printed page and GHS 3.00 per spiral binding. Ask for the quantity of each service and print an itemised bill with a total. Use printf so the amounts line up with two decimal places.

  7. 7

    Add use strict and use warnings to your printing shop script. Then deliberately introduce three different mistakes (for example a misspelled function name, a missing quotation mark, and a variable used before it is given a value) and record the error or warning each one produces.

  8. 8

    Write a script that reads a number from the user and prints its multiplication table from 1 to 20, neatly formatted.

  9. 9

    Use perldoc to look up the functions chomp, chop, rindex, abs and int. Write a script that demonstrates each one with a value of your choice, with a comment explaining what each does.

  10. 10

    Create an array of ten player names for a football squad. Print the first player, the last player and the number of items. Then remove the first two players, add one player at the end, and print the final array.

Questions 11 to 20

  1. 11

    Store six race times (in seconds) for an athlete in an array and print the total, average, fastest (lowest) and slowest (highest), without using any modules.

  2. 12

    Repeat the previous question using List::Util (sum, max, min). Compare the two versions: which is shorter, and which is easier to read?

  3. 13

    Store the names of eight football clubs in an array. Print them in alphabetical order, then in reverse alphabetical order, then sorted by the length of the name.

  4. 14

    Create a hash that maps six region names to their capital cities. Print all of them sorted by region. Then ask the user for a region and print its capital, or the message "Region not found".

  5. 15

    Store the balances of three susu (savings) groups, for example Unity, Progress and Hope, in a hash. Write code to deposit into a group's account, withdraw from a group's account (refusing the withdrawal if the balance is too low), and print the final balances.

  6. 16

    Write a script that takes a list of product names bought during a day and counts how many times each product appears, using a hash. Print the result from most frequent to least frequent.

  7. 17

    Given an array that contains duplicates, such as ("Ama", "Kofi", "Ama", "Esi", "Kofi", "Yaw", "Esi"), build a new array with the duplicates removed while keeping the original order.

  8. 18

    Create an array of arrays holding the scores of five athletes in four rounds. Print a table showing each athlete's total and average.

  9. 19

    Use an array of hashes to store records for five employees (name, staff ID, department, salary). Print all records as a formatted table, then print only the employees in the Finance department.

  10. 20

    Read an attendance percentage between 0 and 100 and print a status (Excellent, Good, Warning or Critical) using boundaries your group chooses. Reject values outside the range.

Questions 21 to 30

  1. 21

    Write a number guessing game. The program picks a random number from 1 to 30, the user has 5 tries, and the program says "go up" or "go down" after each wrong guess.

  2. 22

    Print all multiples of 5 from 1 to 120. Then print all numbers from 1 to 150 that are divisible by both 2 and 7.

  3. 23

    FizzBuzz variant: for the numbers 1 to 70, print "Zip" for multiples of 4, "Zap" for multiples of 7, and "ZipZap" for multiples of both; otherwise print the number. Then change the program so the words and divisors come from a hash.

  4. 24

    Write a script that checks whether a number entered by the user is prime. Extend it to list all prime numbers between two limits entered by the user and print how many there are.

  5. 25

    A library self-service kiosk asks for a 4-digit PIN and allows 4 attempts. After a correct PIN, show a menu (view fines, pay fine, extend loan, exit) that repeats until the user chooses exit.

  6. 26

    Print a right-angled triangle made of the # character, aligned to the right-hand side, whose height is given by the user, then print an inverted version.

  7. 27

    Write a script that computes the sum of the digits of a number using a loop, and a second one that prints the first N powers of 2 (1, 2, 4, 8, ...).

  8. 28

    A car park charges by parking duration (up to 1 hour, over 1 hour up to 4 hours, over 4 hours) and vehicle type (motorbike, car, bus). Ask for both and print the charge. Store the rates in a hash instead of writing a long if-elsif chain.

  9. 29

    Using last and next, write a loop that reads numbers from the user until they type "quit". Ignore zero and negative numbers, and print the sum, count and largest of the valid ones.

  10. 30

    Read a sentence and print the number of characters, words and uppercase letters in it.

Questions 31 to 40

  1. 31

    Check whether two words entered by the user are anagrams of each other, ignoring case and spaces (for example "listen" and "silent"). Test it on at least eight pairs and show the results.

  2. 32

    Take a full name typed in any case, such as "efua NYAMEKYE owusu", and print it properly capitalised ("Efua Nyamekye Owusu"), followed by the initials ("E. N. O.").

  3. 33

    Validate GhanaPost GPS digital addresses: accept two capital letters, a hyphen, three digits, a hyphen and four digits (for example GA-543-2917), and reject everything else. Test your pattern on at least 10 inputs and show the results.

  4. 34

    A text file contains messy lines with hashtags (words starting with #) buried inside them. Use a regular expression to extract every hashtag and print the unique ones in alphabetical order, ignoring case.

  5. 35

    Write a script that validates hostel room codes in a format your group defines (for example BLK-C-214). Show it accepting at least 5 valid codes and rejecting at least 5 invalid ones.

  6. 36

    Use the substitution operator s/// to replace every occurrence of a word in a paragraph, ignoring case. Print the paragraph before and after the replacement, together with the number of replacements made.

  7. 37

    A file contains phone numbers written as 0244123456. Convert every number to the format 024 412 3456 using regular expression captures, and leave the rest of each line unchanged.

  8. 38

    Use split to break the line "Esi:Owusu:PHY:100:58", whose fields are separated by colons, into fields and print each one with a label. Then use join to print the fields separated by a comma and a space.

  9. 39

    Read a paragraph and count the sentences, find the longest sentence, and find the ten most common words, ignoring common words such as "the", "and" and "is".

  10. 40

    Write a script that reads a text file and prints every line with its line number and its length in characters. Create your own test file.

  6. 46

  8. 48

  9. 49
